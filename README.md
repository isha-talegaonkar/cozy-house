# 🍂 The Cozy House

A slow-living, Sims-inspired little house to fall asleep to. June, Theo and their cats Biscuit and Mochi go about their day: painting, sewing, cooking, reading by the fire and napping in sunbeams.

Runs entirely in the browser (Three.js, no build step). Open `index.html` or visit the GitHub Pages site.

- ⟲ ⟳ rotate the house
- Speed 1× / 5× / 20×
- ♪ generated ambient music + fire crackle
- Scroll to zoom

`style-previews/` holds the early style explorations.
